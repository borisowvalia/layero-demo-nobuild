# layero-demo-nobuild

Фикстура для демонстрации: **платформа не выдумывает команду сборки**.

В `package.json` есть скрипты `dev` и `test` — и нет `build`. Фреймворк по
такому дереву не опознаётся: пресет `generic`, у которого в спеке детекта прямо
записано `"fallback": null` — своего умолчания нет.

Что должно произойти:

* в мастере поле «Команда сборки» показывает **перечень вариантов** приглушённо
  (`bun run build, pnpm run build, yarn build или npm run build`), а не
  подставленное `npm run build`;
* если ничего не вписать, сборка отказывает текстом, который называет причину и
  действие: «не знаем, чем собирать: команда не задана, а в package.json нет
  скрипта build (скрипты: dev, test)».

До 26.08.2026 платформа подставляла `npm run build` и запускала его. Проект
`guideava-phuket-bot` так получил девять одинаковых отказов за десять дней:
ошибка менеджера пакетов вместо объяснения, откуда взялась команда.

---

## Проверено на проде 26.08.2026

Проект `demo-nobuild`. Сборка отказывает так:

```
не знаем, чем собирать этот проект: команда сборки не задана, а в package.json
нет скрипта «build» (скрипты: dev, test). Платформа не подставляет команду за
вас — фреймворк «generic» своего умолчания не объявляет. Укажите команду сборки
в настройках проекта или в layero.json: она будет выполнена дословно.
```

До 26.08.2026 на этом месте запускалось `npm run build`, которого в репозитории
нет, и человек читал ошибку менеджера пакетов.

⚠️ Первая сборка этой фикстуры вскрыла дефект в самой правке: ветка отказа
падала `NameError` вместо текста — 434 юнита билдера её не исполняли ни разу.
Ради этого фикстура и заводилась.
